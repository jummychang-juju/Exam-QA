## T-001 唯讀查詢端點（建議程式碼）

- **狀態**：待驗收
- **目標**：寫出 Apps Script `doGet` 的建議程式碼，給啾咪手動貼到新專案部署。
- **輸入**：`?sid=學號`
- **輸出 JSON**：`{ status, approvedDate, expireDate, maskedAccount }`
- **驗收標準**
  - [ ] 只讀取「開通紀錄」分頁，不寫入任何資料
  - [ ] 程式碼中沒有 GmailApp、MailApp、DriveApp 權限修改
  - [ ] 學號格式錯誤時回傳 `status: "invalid"`
  - [ ] 帳號遮罩：保留前 2 碼和網域，其餘用 `*`
  - [ ] 使用 CacheService，同一學號 10 分鐘內不重複讀表
  - [ ] REPORT 裡附上部署步驟（部署為網頁應用程式、執行身分、存取權）
- **交付方式**：寫在 REPORT.md。repo 是公開的，所以程式碼中的試算表 ID 一律用 `請貼上試算表ID` 佔位，由啾咪部署時自行填入

## T-002 公開查詢頁 index.html

- **狀態**：待辦（等 T-001 完成）
- **目標**：單檔 HTML 查詢頁，部署到 GitHub Pages。
- **驗收標準**
