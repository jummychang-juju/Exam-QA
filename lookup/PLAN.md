# PLAN：考古題申請公開查詢頁

> 只有規劃師可以修改本檔。

## 目標

申請者寄出「考古題申請」信之後，系統**不會回信**（避免 Gmail 被鎖）。
需要一個公開查詢頁，讓申請者自己輸入學號，查看申請是否已開通。

## 使用者

- 衛道國中部學生與家長（手機為主）
- 啾咪（管理者，確認頁面資料是否最新）

## 架構

```
開通紀錄（Google 試算表，管理用，不公開）
        │
        ▼
Apps Script 唯讀查詢端點 doGet（啾咪手動部署）
  - 輸入：學號
  - 輸出：只回傳「狀態、開通日期、到期日、遮罩後的帳號」
        │
        ▼
GitHub Pages 單檔 HTML 查詢頁（開發師負責）
```

- 試算表本身**不可**公開發布，所以前端不能直接讀 CSV。
- 唯讀端點由開發師寫在 REPORT 的「建議程式碼」，啾咪手動貼到一個**新的** Apps Script 專案部署。不改動原本的開通主程式。

## 範圍內

- 學號輸入、查詢結果顯示（已開通／處理中／查無申請／格式錯誤）
- 帳號遮罩，例如 `ab****@gmail.com`
- 申請說明（寄件規則、主旨、到期規則：學號前 3 碼 + 3 年的 6/30）

## 範圍外

- 任何寄信、通知
- 線上申請表單（維持用 Email 申請）
- 修改開通主程式

## 隱私考量

- 任何人輸入別人的學號都查得到結果，所以回傳內容只有狀態和日期，帳號必須遮罩。
- 端點要限制查詢頻率（同一學號連續查詢可用快取），避免被大量掃描。
